# meshloop-adapters

Herdr, git worktree, SQLite, and fixture-harness adapters for
[Meshloop](https://github.com/smota/meshloop). `fixture_harness` is the CI
double, not a product worker.

This crate is an implementation crate. Install the engine with:

```text
cargo install meshloop-cli --locked
```

Then [Install and setup](https://github.com/smota/meshloop/blob/main/docs/install.md).
