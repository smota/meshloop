# Meshloop brand

Canonical mark: [`logo.svg`](logo.svg) (1:1 disc, no letters).

| File | Use |
|---|---|
| `logo.svg` | README and identity |
| `logo-128.png` | PNG fallback |
| `logo-512.png` | Avatar / high-DPI |
| `logo-32.png` | Small-size proof |
| `social.png` | GitHub Settings → Social preview (1280×640) |

The mark is a closed teal ring on a graphite disc. Four nodes sit on the ring; the bottom node is a copper square (human accept). Do not recolor teal to purple, add letters inside the disc, or treat Apache-2.0 as a trademark license. See [`TRADEMARKS.md`](../../../TRADEMARKS.md).

GitHub has no public API for the social preview. After changing `social.png`, upload it at **Settings → General → Social preview**.
